- [x] 道路恢复/费用改善后的收益扫描、原生收益门槛与冷却时间；HTTP/CLI、Python 场景、Benchmark 与工作台接入，Agent 收到改善通知后自主决策。
- [x] 限制感知双向 Dijkstra/A*：反向边态搜索保留正向禁转/罚时语义，600 组场景对拍。
- [x] LPA* 增量路由：边态反向修复、会话缓存与淘汰、精确路径提交、仿真/Agent/Benchmark/界面接入。见 [实现说明](incremental-routing.md)。
- [x] D* Lite：移动起点启发式、二元优先级与延迟更新、封路/费用增量修复，沿用有界会话缓存和精确路径快照；仿真/Agent/Benchmark/界面接入。
- [x] 时间依赖路由：FIFO 分时速度 Dijkstra、部分道路与转向语义、按出发时间缓存；HTTP/CLI、仿真/Agent/Benchmark 与工作台接入。边界见 [实现说明](time-dependent-routing.md)。
- [x] ALT 地标 A*：有向距离预处理、按需复用、有界距离表、禁转与动态费用最优性；HTTP/CLI、仿真/Agent/Benchmark 与界面接入。见 [实现说明](alt-routing.md)。
- [x] 静态 CH 收缩层级：按转向规则选择路口/边状态、捷径与禁转/罚时、双向向上查询、原始道路展开、预算核心图；动态路况明确回退。HTTP/CLI、仿真/Agent/Benchmark 与界面接入。见 [实现说明](ch-routing.md)。
- [x] Via-way：OSM 有序道路链提取、`.zmap` v3、历史状态路由、自定义算法与车辆重规划、精确提交和重放；加速入口明确回退。见 [实现说明](via-way-routing.md)。
- [ ] 后续路由：conditional/access；可定制 CH、持久化预处理与多目标路线。
- [ ] 大规模执行：性能基准、分片 Worker、异步批量仿真、分块回放与 WebSocket。
- [ ] 地图与工作台：MVT/LOD、mmap、GPS 匹配、浏览器修复/重编译及差异比较。
- [ ] 生产能力：认证、项目、配额、容器隔离、分布式任务、持久化导入队列。部署暂按单机私有使用；多用户选型待确认。
- [ ] 协议与调试：gRPC、生成式 protobuf、原生 barrier 与高级调试。
- [ ] 扩展研究：记忆、多智能体、微观/中观混合仿真。

快照仍有边界：旧版不验证、SHA-256 不做来源认证、地图版本文件尚未自动回收；契约兼容不等于跨平台位级重现。
